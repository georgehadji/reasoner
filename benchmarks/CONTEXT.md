# Context: Benchmarks

## Directory: `benchmarks`

## Description
Includes comparative benchmarks for evaluating reasoning methodologies, latencies, calibrations, and overhead of various providers and prompt strategies.

- **`benchmark_vs_latency.py`**: Latency benchmark: VS vs baseline per deployment profile.
