# Context: Image

## Directory: `src/reasoner/infrastructure/watermark/image`

## Description
Watermarking implementations for applying invisible pixel tags or visual overlays on images.

## Files
- **`__init__.py`**: Python package initialization module.
- **`detect.py`**: Magic-byte format detection for images (PNG/JPEG/WebP/AVIF/HEIC).
- **`isobmff.py`**: AVIF/HEIC C2PA / AI-provenance metadata inspection and stripping.
- **`jpeg.py`**: Code or resource asset facilitating system functionality.
- **`markers.py`**: C2PA / AI-provenance marker vocabulary shared by every image format module.
- **`png.py`**: Private/ancillary chunks sometimes used for JUMBF/C2PA containers.
- **`registry.py`**: Format -> scrubber-module dispatch registry.
- **`webp.py`**: WebP C2PA / AI-provenance metadata inspection and stripping.
