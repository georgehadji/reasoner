# Context: Benchmarks

## Directory: `src/reasoner/infrastructure/benchmarks`

## Description
Implementations for executing benchmarking suites and aggregating performance metadata.

## Files
- **`__init__.py`**: Benchmark infrastructure for model capability evaluation (ACR Phase 7).
- **`engine.py`**: Benchmark engine — orchestrates model capability evaluation (ACR Phase 7).
- **`runner.py`**: Async benchmark runner with rate limiting and cost caps (ACR Phase 7).

## Subfolders
- **`suites`**: Specific benchmarking implementations (e.g. latency, diversity, calibration).
