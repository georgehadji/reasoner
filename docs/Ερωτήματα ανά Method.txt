Ερωτήματα ανά Method
  1. Multi-Perspective
  Ερώτημα: «Πρέπει να εισαγάγω 4ημερη εργασία στην εταιρεία μου. Να αναλύσεις τα
  πλεονεκτήματα, τους κινδύνους, τις μακροπρόθεσμες επιπτώσεις και τον ελάχιστο
  απαιτούμενο πόρο από κάθε οπτική γωνία.»
  Γιατί ταιριάζει: Το ερώτημα ζητάει εξ ορισμού πολλαπλές οπτικές (constructive,
  destructive, systemic, minimalist), που είναι ακριβώς ο σκοπός της method.
  ──────────────────────────────────────────────────────────────────────────────
  2. Iterative
  Ερώτημα: «Σχεδίασε έναν αλγόριθμο πρότασης δώρων για e-shop. Ξεκίνα με μια πρώτη έκδοση, 
βρες τα αδύνατα σημεία της, βελτίωσέ την, και επανέλαβε μέχρι να φτάσεις σε ένα robust και scalable σχέδιο.»
  Γιατί ταιριάζει: Η iterative method λειτουργεί με γενιές και κριτική. Το ερώτημα προσδιορίζει ρητά αυτόν τον βρόχο βελτίωσης.
  ──────────────────────────────────────────────────────────────────────────────
  3. Debate
  Ερώτημα: «Τα υβριδικά μοντέλα εργασίας είναι καλύτερα από την πλήρη τηλεργασία; 
Να παρουσιαστούν δύο αντιμαχόμενες θέσεις (υπέρ υβριδικού / υπέρ πλήρους remote) 
και στο τέλος να αξιολογηθεί ποια επικρατεί με βάση την ορθολογική επιχειρηματολογία.»
  Γιατί ταιριάζει: Η debate method χρησιμοποιεί δύο αντιπάλους (A/B) και έναν κριτή. 
Το ερώτημα είναι δομημένο για αντιπαράθεση απόψεων.
  ──────────────────────────────────────────────────────────────────────────────
  4. Scientific
  Ερώτημα: «Ισχύει ότι η τεχνητή νοημοσύνη μειώνει την παραγωγικότητα των προγραμματιστών junior; 
Να διατυπωθούν υποθέσεις, να αναζητηθούν εμπειρικά δεδομένα και να ελεγχθούν με falsification tests πριν καταλήξεις σε συμπέρασμα.»
  Γιατί ταιριάζει: Η scientific method βασίζεται σε υποθέσεις, falsification και
  εμπειρικά δεδομένα — ακριβώς ό,τι ζητάει το prompt.
  ──────────────────────────────────────────────────────────────────────────────
  5. Socratic
  Ερώτημα: «Τι σημαίνει ‘ηθική χρήση AI’ σε μια εταιρεία; Μην μου δώσεις απευθείας απάντηση. 
Ξεκίνα με καίριες ερωτήσεις (maieutic) που θα με οδηγήσουν να ανακαλύψω μόνος μου τις αρχές και τις αντιφάσεις μου.»
  Γιατί ταιριάζει: Η socratic method χρησιμοποιεί ερωταποκρίσεις για να οδηγήσει
  τον χρήστη στην αυτο-ανακάλυψη της γνώσης.
  ──────────────────────────────────────────────────────────────────────────────
  6. Research
  Ερώτημα: «Ποια είναι η τρέχουσα κατάσταση της αγοράς για LLMs που τρέχουν locally σε consumer hardware (2026); 
Να κάνεις deep web research, να αξιολογήσεις τις πηγές και να συνθέσεις μια ενημερωμένη εικόνα με citations.»
  Γιατί ταιριάζει: Η research method κάνει iterative web search, vetting πηγών κ
  αι σύνθεση. Το prompt ζητάει live έρευνα και citations.
  ──────────────────────────────────────────────────────────────────────────────
  7. Jury
  Ερώτημα: «Πρέπει να επιλέξω tech stack για ένα νέο fintech startup (2026). Να
  παράγεις 3-4 ανεξάρτητες προτάσεις από διαφορετικούς ‘ειδικούς’, να τις κριτικάρεις, 
να τις επαληθεύσεις και να καταλήξεις σε μια ενιαία, βαρυνόμενη σύσταση
  με αιτιολόγηση αξιοπιστίας.»
  Γιατί ταιριάζει: Η jury method χρησιμοποιεί generation pool → critic pool → verification & meta-evaluation. 
Το prompt απαιτεί πολλαπλές προτάσεις, κριτική και ranking.
  ──────────────────────────────────────────────────────────────────────────────
  8. Pre-Mortem
  Ερώτημα: «Σχεδιάζουμε να λανσάρουμε ένα νέο προϊόν AI σε 6 μήνες. Κάνε pre-mortem: φαντάσου ότι το προϊόν απέτυχε καταστροφικά. 
Περιέγραψε την αφήγηση της αποτυχίας, εντόπισε το root cause pivot, τα early warning signals και πρότεινε
  ένα σκληρυμένο redesign με safeguards.»
  Γιατί ταιριάζει: Η pre-mortem method είναι σχεδιασμένη για failure narrative →
  backtrack → signals → redesign. Το prompt το καθορίζει ρητά.
  ──────────────────────────────────────────────────────────────────────────────
  9. Bayesian
  Ερώτημα: «Ποια είναι η πιθανότερη αιτία της απότομης πτώσης conversions στο eshop μας τον τελευταίο μήνα; 
Να διατυπώσεις 3-4 ανταγωνιστικές υποθέσεις, να εκτιμήσεις priors, να αξιολογήσεις το evidence (likelihood) 
και να υπολογίσεις posteriors με sensitivity analysis.»
  Γιατί ταιριάζει: Η bayesian method ακολουθεί priors → likelihood → posterior →
  sensitivity. Το prompt ζητάει ρητά Bayesian reasoning.
  ──────────────────────────────────────────────────────────────────────────────
  10. Dialectical
  Ερώτημα: «Η αυτοματοποίηση μέσω AI οδηγεί σε απώλεια θέσεων εργασίας (thesis)
  ή σε δημιουργία νέων ρόλων (antithesis); Να διατυπώσεις και τις δύο θέσεις, να
  εντοπίσεις τις αντιφάσεις και να συνθέσεις μια aufhebung που διατηρεί τα strengths και από τις δύο πλευρές.»
  Γιατί ταιριάζει: Η dialectical method χρησιμοποιεί thesis → antithesis → contr
  adictions → aufhebung. Το prompt είναι κλασικά hegelian.
  ──────────────────────────────────────────────────────────────────────────────
  11. Analogical
  Ερώτημα: «Πρέπει να βελτιώσω την ανθεκτικότητα του supply chain μου απέναντι σε κρίσεις. 
Να βρεις ένα ισόμορφο (isomorphic) πρόβλημα από άλλο domain (π.χ. βιολογικά συστήματα, δίκτυα υπολογιστών, 
οικοσυστήματα), να χαρτογραφήσεις τις αναλογίες και να μεταφέρεις λύσεις από το source domain στο δικό μου.»
  Γιατί ταιριάζει: Η analogical method κάνει abstraction → domain search → mapping → transfer. 
Το prompt ζητάει ρητά cross-domain analogy.
  ──────────────────────────────────────────────────────────────────────────────
  12. Delphi
  Ερώτημα: «Πόσο πιθανό είναι ότι η τεχνητή γενική νοημοσύνη (AGI) θα επιτευχθεί
  έως το 2035; Να ζητήσεις ανεξάρτητες εκτιμήσεις από 4 ‘ειδικούς’ (γιατί κάθε ένας 
χρησιμοποιεί διαφορετικά δεδομένα), να τις συγκεντρώσεις ανωνύμως, να δώσεις feedback 
και να δεις αν υπάρχει σύγκλιση σε δεύτερο γύρο.»

  Γιατί ταιριάζει: Η delphi method χρησιμοποιεί independent expert estimates → aggregation → anonymous feedback → convergence. 
Το prompt ταιριάζει απόλυτα σε forecasting ερωτήματα.
