# Context: Docs

## Directory: `ui-next/src/app/docs`

## Description
Browsers-friendly system documentation renderer and page views.

## Files
- **`layout.tsx`**: Shared chrome for every documentation page. The sidebar is rendered by each page rather than here so it can mark the active entry.
- **`page.tsx`**: React page view component rendering the primary route content.

## Subfolders
- **`[slug]`**: Exposes routing, templates, or integrations for [slug] within the 'ui-next/src/app/docs' ecosystem.
