# Context: Src

## Directory: `ui-next/src`

## Description
Source directory for the Next.js React codebase.

## Files
- **`proxy.ts`**: Code or resource asset facilitating system functionality.

## Subfolders
- **`app`**: The visual page views, routes, layouts, and API routes of the Next.js 16 app router.
- **`components`**: React visual and interactive UI components.
- **`hooks`**: Custom React hooks used to query backend web-sockets and fetch APIs.
- **`lib`**: Surgical utility libraries for color schemes, API clients, and visual calculations.
- **`stores`**: Zustand global clientside memory stores orchestrating active chat sessions.
- **`test`**: Exposes routing, templates, or integrations for Test within the 'ui-next/src' ecosystem.
