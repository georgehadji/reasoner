# docs — Folder Map

**Purpose:** Reference documentation plus a large archive of implementation plans. Roughly a third of this folder is **living reference** (ADRs, CODEMAPS, ENVIRONMENT, METHODS, MCP, monitoring); the rest is **historical plans and audits** kept for provenance. Check the living set first — a plan describes intent at a point in time, not necessarily current behavior.

## Key gotchas

- Several docs are in Greek by design (`METHOD_COMPARISON.md`, `article_workflow_explained_el.md`, `agent_memory_structures_2.md`, `Ερωτήματα ανά Method.txt`) — not corruption.
- `ARCHITECTURE_MINDMAP.md` counts are machine-patched; do not hand-edit those lines.
- Code comments reference plans by phase, e.g. "security-remediation-plan.md Phase 5 item 1". When you see one, that plan file is the spec for that code.
- A plan existing does not mean it shipped. Verify against the code before treating it as current.
